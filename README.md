# CC-CEDICT

Unmodified snapshots of the community-maintained Chinese-English dictionary published by [MDBG](https://www.mdbg.net/chinese/dictionary?page=cc-cedict).

Download the original gzip exports from [Releases](https://github.com/oxalis-ink/cc-cedict/releases). Release tags identify the version and export timestamp from the dictionary header.
